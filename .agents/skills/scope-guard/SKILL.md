# スコープ評価

提案された機能について以下を確認する。

- 誰の課題を解決するか。
- コア価値に関係するか。
- Webアプリとして実装する意味があるか。
- デモで価値が伝わるか。
- 実装コストはどの程度か。
- 技術的リスクはあるか。
- 他機能への依存はあるか。
- テストコストはどの程度か。
- Must機能の完成度を下げないか。
- 2026-10-12のCode Freezeまでに完成可能か。

以下に分類する。

- Must
- Should
- Could

AIは最終的な採否を決定しない。

以下を提示する。

- 期待できる価値
- 実装への影響
- リスク
- 代替案
- この機能を追加する場合に削るべきもの

ShouldやCouldを増やすことでMustの完成度を下げない。
