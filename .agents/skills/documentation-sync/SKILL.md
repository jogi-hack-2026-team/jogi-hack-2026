# ドキュメント同期

すべての変更について、ドキュメントへの影響があるか確認する。毎回すべての文書を更新する必要はなく、変更に関係する正本だけを必要に応じて更新する。
正式採択の記録は [AI開発ツールガイド](../../../AI_DEVELOPMENT_TOOLS.md#採択済みの運用方針) を参照する。

文書運用と詳しい執筆・保守手順の正本は[CONTRIBUTING](../../../CONTRIBUTING.md#文書を書く手順)。対象Issueと関連仕様を読み、該当する手順を順に実行する。履歴・現行契約・対応表の更新先は[変更に伴う文書更新](../../../CONTRIBUTING.md#変更に伴う文書更新)、全文移動は[履歴の配置と移動](../../../CONTRIBUTING.md#履歴の配置と移動)で決める。
