# セルフレビュー

変更全体を対象Issueと照合して確認する。

## 仕様

- Issueの完了条件を満たしているか。
- Issueのスコープ外の変更がないか。

## コード

- 命名から意図が理解できるか。
- 責務が不自然に集中していないか。
- 型が適切か。
- エラー処理が適切か。
- 境界値を考慮しているか。
- データの不変条件を壊していないか。
- セキュリティ上の問題を増やしていないか。

## テスト

- 必要なテストが存在するか。
- 既存テストが通るか。
- Regression Testが必要ではないか。

## UI

- ユーザー向け変更は実ブラウザで確認したか。
- UXやアクセシビリティに明らかな問題がないか。

## ドキュメント

- READMEが古くなっていないか。
- セットアップ手順が変わっていないか。
- 環境変数が変わっていないか。
- アーキテクチャが変わっていないか。
- 重要な技術判断をADRとして残す必要がないか。

結果を以下に分類する。

- Blocking
- Should Fix
- Optional

AI自身のレビューをHuman Reviewの代替にしない。
