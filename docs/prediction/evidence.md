Supporting Artifact / Not a Source of Truth。正式な判断は[Architecture](../architecture.md#prediction-engine)と[判断記録](decision-log.md)。

- **種別**：LOCAL_POC（合成データによる数値実験）。実ユーザーデータでの検証は未実施。
- **実施日・環境**：2026-09-30、Node 25、使い捨てスクリプトを[実験フォルダ](../../experiments/prediction-model-validation/README.md)に保存。
- **共通条件**：必要回数 `N = 120`（例：30分×120回）。記録なし（UNKNOWN）をランダムに10%混ぜる。「連続中」の文脈（昨日まで2日以上続けていた状態で今日を判断）で差が出やすいので、主にこの文脈で評価した。
- **支持しない主張**：人の行動がMarkov連鎖であること、実ユーザーでの精度、表示が行動を変える効果。

## モデル選択

同じ観測（M2で状態が決まる遷移）に対する周辺尤度から、M0 / M1 / M2の事後確率を計算した（各300人、Beta(1,1)）。事後確率0.9超でどれかに決まった割合は、全User・14/30/60日で0〜5%（Bの60日でM2が5%）。残りの95〜100%は判定保留。

## DPとMonte Carloの比較

- **恒等式**：a = 0.8、b = 0.3 で、SKIP開始の到達日分布と「DONE開始の分布 ⊕ Geometric(b)」の差は最大1.04e−17（0〜900日）。
- **期待値差**：4ユーザーとも、漸化式のΔと到達日分布DPの平均差が小数点以下6桁まで一致（例：B 4.444444）。
- **固定θでのMC（2,000試行）とDP**：P50・P80の差は最大1日。
- **CRNの効果（旧方式）**：P50差の標準偏差 1.09日 → 0.49日。DP方式ではCRN自体が不要。
- **実行時間**：完了の目安（K=200、N=120）163ms、K=500で394ms。seedを変えた5回のP50は203〜212日（表示を週単位に丸める理由）。
- **最悪ケース（仕様どおりの乱数・サンプラー）**：配列を毎日作り直す素朴なDPでは`requiredFutureDone = 400`で約1秒、1095で約3秒。配列の使い回しと「残り日数で届かない状態」の刈り込みを入れると、120・400・600・800・1000・1095の全条件で最大約260ms（結果は素朴なDPと一致）。Goalの上限は設けない。`bench.mjs` / `bench2.mjs`。

## 記録漏れの影響（2状態、60日×200人）

やらなかった日の記録が確率mで抜ける場合（真のa = 0.8、b = 0.3）：m = 0で推定b 0.34、m = 0.3で0.40、m = 0.6で0.54。bが高めに出るため、遠ざかる日数は小さめ（控えめ側）、完了の目安は早め（楽観側）になる。
