# Issue単位の草稿・実施・移行記録

Supporting Artifact / Not a Source of Truth

現在のProduct仕様は[Product Spec](../product-spec.md)、実現方法は[Architecture](../architecture.md)、コードと確認方法の入口は[change-map](../change-map.md)。このフォルダは過去の草稿・検証結果・移行の詳細を保存する場所で、現行契約の追加正本ではない。

記録は`issue-<実在Issue番号>-<内容>.md`で探す。GitHubではこのフォルダのファイル一覧、ローカルでは`git ls-files docs/changes`を使う。ファイルごとの手動一覧は保守しない。追加・訂正・全文移動の規則と検査方法は[CONTRIBUTING](../../CONTRIBUTING.md#履歴の配置と移動)を参照する。

既存のoperations・experiments・領域別decision-logにある詳細は元の記録を参照し、ここへ複製しない。記録中の候補・未採択・未実施を現在の保証へ読み替えない。
